# AI Workout Coach

An AI-powered workout assistant that answers fitness questions using a
Retrieval-Augmented Generation (RAG) pipeline.

## Features

- Ask workout questions
- Exercise explanations
- Workout program generation
- Retrieval-based answers from fitness knowledge

## Tech Stack

- Python
- LangChain
- OpenAI
- ChromaDB
- FastAPI
- Streamlit

## Architecture

Documents → Embeddings → Vector DB → Retriever → LLM → API → Chat UI
